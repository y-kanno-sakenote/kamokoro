## v7.2 ロマン技の威力（2026-09-06・実測で確定。動かしたのは12本の `power` だけ）

**問題**: v7.1までのロマン技（コスト3・当たり目1面・威力30〜45）は、**EV型CPUが1手も選ばなかった**（6体すべて 0.0% / 約9万手番）。
既定ダイスでの成功率は 21.3%（1801号だけ 25.5%）で、期待ダメージは 7.1〜11.0。安定技（11.7〜12.4）にも中技（11.2〜18.7）にも届かない。
人間が「威力最大を毎回狙う」自然な遊び方（ロマン優先）をすると対CPU **25.4%**（18.8〜32.6%）で、看板の大技を撃つほど損をしていた。

**直した値**（★＝既定4技に入るほう／もう1本は非★）

| キャラ | ★ロマン | 前 → 後 | 非★ロマン | 前 → 後 |
|---|---|---|---|---|
| 🏺協会6号 | 秋田の底力 | 35 → **60** | おおむかし | 40 → **65** |
| 🍶協会7号 | 真澄の一撃 | 35 → **60** | あわだらけ | 40 → **65** |
| 🍈協会9号 | 熊本の華 | 35 → **60** | おおころがり | 40 → **65** |
| ❄️協会10号 | 東北の底冷え | 35 → **60** | おおふぶき | 40 → **65** |
| 🍏協会14号 | 酸なしの美 | 30 → **55** | おおみず | 40 → **65** |
| 🧬協会1801号 | りんご香バースト | 40 → **75** | ぜんぶだす | 45 → **80** |

- **設計の線**: 既定ダイスでの期待ダメージ（`cpuChoose` の評価値）が**安定技より上・中技と並ぶ**ところに置く。ここを越えると CPU の技選びが「安定⇔中」から「中⇔ロマン」に切り替わる。**これは連続ではなく段差**で、越えた瞬間にロマン選択率が 0% → 37% に飛ぶ（安定技より下だと 0% のまま）。中間の値は存在しない
- **1801号だけ +35**（他は +25）。とくせい「ロマン」で**失敗すると自分に10**を負うので、同じ賭けでも取り分が大きくないと合わない。+25（威力65）では「ロマン優先 vs CPU」が 36.8% で目標40%に届かなかった
- **14号は他より1段低い55**（他5体は60）。「軽い」持ち味を残すため。これでも選択率37.0%・ロマン優先44.2%で目標を満たす
- 当たり目・効果値（+10 / 自分に10 / 相手の次エネコロ-1）・コスト・HP・他区分の技は**1つも触っていない**

### 実測（前 → 後）
| 指標 | v7.1 | v7.2 | 目標 |
|---|---|---|---|
| EV型CPUのロマン技選択率（6体） | **0.0%** 全滅 | **36.8〜48.9%** | 15%以上 |
| ロマン優先 vs EV（6体） | 18.8〜32.6%（総合25.4%） | **42.6〜45.5%（総合44.1%）** | 40%以上 |
| 堅実優先 vs EV（6体） | 35.9〜43.7% | 42.5〜45.6%（総合43.8%） | — |
| 42通り勝率レンジ ON（8000戦） | 45.0〜56.8% | **45.3〜55.1%** | 30〜70% |
| 42通り勝率レンジ OFF | 45.1〜58.2% | **45.9〜55.1%** | 35〜65% |
| 6体の総合勝率 ON / OFF | 48.0〜51.2% | **49.0〜51.0% / 48.8〜50.8%** | 45〜55% |
| 平均手番（片側） | 7.7 | **6.8 / 6.7** | 5〜10 |
| 宣言成功率（全体） | 67.0% | **43.4%** | 40〜70% |
| 天井（上限内最強 vs 既定） | 88.7% | **88.9%** | 90%以下 |

- **どう遊んでも損しない線に乗った**: ロマン優先44.1% ／ 堅実優先43.8% ／ EV50.0%。3つの遊び方の差が0.3ptまで縮んだ（v7.1は ロマン優先25.4% / 堅実優先39.6% / EV50.0% で25ptの開き）
- **天井は動かなかった**（88.7% → 88.9%）。積み切った構成はもともとロマン技抜きで上限近くに届いていたため
- **成長の弧は成立している**: 既定ダイスでのロマン技の成功率 **21.3% → 積み切った型で 61.6%**（1801号だけ 25.5% → 40.7%＝コストが🍚💧🔥の3種で1面に積めない）。CPUの選択率も 37% → 50%。**最初は博打、集めたら主砲**

### 引き受けた副作用（帯を外れた組）
- **宣言成功率が 67.0% → 43.4% に下がった**（全体では帯 40〜70% の中）。CPUが「中技⇔ロマン技」の交互になり、成功率87.5%の安定技の出番が45% → 9%に減ったため。**そろわない手番が増えるぶん、決まったときの一撃が重い**というトレード
- **14号がらみの6組は成功率が帯を下回る**（36.1〜39.8%）。14号は中技（金沢香40.7%）が元から低く、そこにロマン21.3%が乗ると2手に1手以上そろわない。ロマン威力を下げると選択率が0%に戻る＝**この枠では直せない**（直すなら金沢香の当たり目かコスト。今回は触らない）
- **10号の中技「雪どけ」がほぼ死んだ**（40.8% → 0.9%）。雪どけの期待値11.2が10号の攻撃技で最下位になったため。ロマン威力を50以下にすれば戻るが、その値ではロマンの選択率も0%に落ちる＝**両立しない**（10号の雪どけ自体の話で、ロマン枠では直せない）
- 平均手番が帯を外れる組は**すべて1801号がらみ**（3.9〜5.3）。既知の例外として据え置き

## 1. 属性と3すくみ（v7で効き方が変わった）

| 属性 | キャラ | 有利を取る相手 |
|---|---|---|
| 🌾米 | 🏺協会6号 / ❄️協会10号 | 💧水（米が水を吸う） |
| 🍚麹 | 🍶協会7号 / 🧬協会1801号 | 🌾米（麹が米を糖化する） |
| 💧水 | 🍈協会9号 / 🍏協会14号 | 🍚麹（水が麹を溶かす） |

- **有利な側が先攻**（v7）。ダメージには一切効かない（旧「+2」は廃止）
- **ミラー（同属性）はランダム**。属性が3つで一巡しているので、属性が違えば必ずどちらかが有利になる
- 先攻の得は「**1手目のエネコロが2個**」＝1手ぶん揃いにくい代わりに先に殴れる、というトレードのまま
- 🫧泡 / 🌸香の「タイプ」は**ゲーム画面には出さない**（v7.1で削除）。データ（`CHARS[].type`）は残っているが**どこにも効かない**＝v6.1でドロップを均等にした時点で効果はゼロ。使い道は `docs/zukan.html` の見出しの飾りだけ
- 実装: `engine.js` の `TYPE_ADV` と `newState`（`state.firstReason` が `'adv'`／`'rng'`）。`E.setTypeAdv(true|false)` で ON/OFF（既定ON）。OFFなら先攻は全組ランダム。simは `--noadv` でOFF側を測る

## 2. エネコロ（固定3面＋カスタム3面 × 3個）

- **左・中・右**の3個。表示順＝振るときの並び。**3個それぞれ別々にカスタムできる**
- 1個の6面 = **固定3面（属性×2 ＋ ✨×1・チップ不可・🔒表示）** ＋ **カスタム3面（既定は残り2属性＋🔥）**
  - 例 6号 = 🌾🌾✨ ｜ 🍚💧🔥 ／ 9号 = 💧💧✨ ｜ 🌾🍚🔥。全キャラ同じ形で属性だけが違う
- 先攻1手目の「エネコロ2個」は**左・中**（右を振らない。これは効果ではなく開始時の構造ルールなので固定）。「相手の次エネコロ-1」は**左・中・右のうちランダムに1個が振れなくなる**（2026-09-06 裁定。重なっても消えるのは1個・下限1）
- チップ在庫は**そのキャラのもの**（3個で共通・キャラ間では共通ではない）。差し替え先は **3面×3個＝9スロット**
- **既定は空白ではなく埋まっている**。プレイヤーはそこから差し替える。チップを外すと既定の面（素の面）に戻る＝**空きスロットは存在しない**
- 素の面はチップ在庫に入らない。装着済みチップは外すとそのキャラの在庫に戻る。**キャラ間でチップは行き来しない**（v6.1で在庫をキャラ別にしたため）
- **実装メモ**: `char.slots` の並びは v5 のまま `[属性,属性,他属性,他属性,🔥,✨]`。したがって固定はスロット **0・1・5**、カスタムは **2・3・4**（連番ではない）。並びを変えなかったのは、**既定構成の42通り回帰が v5 と1戦単位で一致する**ことを検算に使うため。画面と sim の表示は `SLOT_ORDER = [0,1,5,2,3,4]`（🔒3面 → カスタム3面）で並べ替える

### チップ一覧（4種・レア無し）
| チップ | 面の意味 | 出方 |
|---|---|---|
| 🌾 / 🍚 / 💧 / 🔥 | そのエネ1個 | 勝つたび1枚（均等1/4）＋ そのキャラを初めて選んだときの8枚 |

✨は**チップではない**（全ダイスの固定面に必ず1つある）。

### 2.1 カスタム上限（v5から据え置き）
- **3面まで積めるのは自分の属性だけ**（固定2面＋カスタム1＝3面）→ 属性チップは1個につき1枚しか載らない
- **他のエネ（他属性・🔥）は1個につき2面まで**（素の1＋チップ1）
- **✨は固定の1面だけ**（チップが無いので上限判定は不要）
- **素の面と同じ種類のチップは、そのスロットに置けない**（面が変わらないのに在庫だけ減るため）。理由は「同じ面です」
- **固定3面にはチップを置けない**。準備画面では🔒＋点線枠で押せなくしてある。理由は「固定の面」
- 上限に達する置き換えはチップをグレーにして選ばせず、理由を短く出す（6号なら「🌾は3面まで」「💧は2面まで」）
- 旧セーブ・壊れたセーブは読み込み時に外して素の面へ戻す（上限違反・廃止された✨チップは在庫に返す）
- 実装: `validateDie` / `validateSlots` / `canPlaceChip(char, chips, die, slot, chip)` / `repairDie` / `repairSlots`
  （`limitFor(char, kind)` = 属性なら `LIMIT_ATTR=3` / それ以外は `LIMIT_OTHER=2`。`FIXED_SLOTS=[0,1,5]` ・`CUSTOM_SLOTS=[2,3,4]`）

### 2.2 初期配布チップ（8枚・選ばせない・2026-09-05 実測で確定）

- 2周目以降・再開時・負けて周をやり直すときには増えない（集めたチップで戦う報酬ループを残す）

## 検討して見送ったもの：v8「✨を勝ち取るチップにする」（2026-09-06・ブランチ `v8-wild-chip` に engine+sim の試作あり）
- 案：✨を固定面から外してレアチップに。固定は属性×2のみ、空いた面はキャラ固有（★4技で属性を除き最も使うエネ）、初期配布に✨1、1周報酬を5択に

- レアが要るなら、土台を壊さず上に載せる「2枚チップ（1キャラ1枚・1周報酬限定）」の方が筋。急がず、遊んでから判断
