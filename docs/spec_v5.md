## v6で変えた5つ（2026-09-05・ユーザー裁定。この枠は動かさない）
1. **エネコロ1個＝固定3面＋カスタム3面**。固定3面＝**そのキャラの属性×2 ＋ ✨×1**。カスタム3面の既定＝**残り2属性＋🔥**
   → 既定の6面は「属性2・他属性1・他属性1・🔥1・✨1」で、**v5の初期ダイスと中身が完全に同じ**
2. **チップを置ける枠は 3面×3個＝9**（v5の12から削減）
3. **✨チップとレア枠を廃止**。チップは🌾🍚💧🔥の**4種だけ**。全ダイスに✨が固定で1面あるので✨チップは意味を持たない
4. **手持ちチップは12枚**（9枠に対して多め＝**何を諦めるか**が準備画面の判断になる）。内訳は**属性3枚＋他3種で9枚**をキャラごとに偏らせる（`docs/characters.md` の表が正）。最初にキャラを選んだときに自動で在庫へ（初回のみ・ピッカーは作らない）
5. **ドロップは勝つたびに🌾🍚💧🔥のどれか1枚**（倒した相手のタイプ寄りが50%＝v5の流儀を踏襲）。**3勝ごとのレアは廃止**

## v2から変えないもの（憲法）
- 戦略は「**どの技を狙うか**」だけ。振り直しは無い。選択肢を足さない
- 効果の語彙は5つ（`+N` / `自分にN` / `相手の次エネコロ-1` / `次に受けるダメージ半減` / `回復N`）。**足さない**（3すくみの+2は「効果」ではなくルール側の加算）
- キャラコロは画面で転がる。UIに専門数値（成功率%・日本酒度など）を出さない。二つ名も出さない
- 数値は全部叩き台。`sim/` で実測してから確定

## 1. 属性と3すくみ（v5から変更なし）

| 属性 | キャラ | 有利を取る相手 |
|---|---|---|
| 🌾米 | 🏺協会6号 / ❄️協会10号 | 💧水（米が水を吸う） |
| 🍚麹 | 🍶協会7号 / 🧬協会1801号 | 🌾米（麹が米を糖化する） |
| 💧水 | 🍈協会9号 / 🍏協会14号 | 🍚麹（水が麹を溶かす） |

- 有利な側は **攻撃技が成功したときのダメージに +2**（固定値・倍率にしない）
- **しずく（失敗時の5ダメージ）には乗らない**。回復技・守り技にも乗らない
- 🫧泡 / 🌸香の「タイプ」は残っているが**戦闘の相性は持たない**（蔵めぐりのドロップ表だけに効く）
- 実装: `engine.js` の `TYPE_ADV` ＋ `ADV_BONUS = 2`。`E.setTypeAdv(true|false)` で ON/OFF（既定ON）。simは `--noadv` でOFF側を測る

## 2. エネコロ（固定3面＋カスタム3面 × 3個）

- **左・中・右**の3個。表示順＝振るときの並び。**3個それぞれ別々にカスタムできる**
- 1個の6面 = **固定3面（属性×2 ＋ ✨×1・チップ不可・🔒表示）** ＋ **カスタム3面（既定は残り2属性＋🔥）**
  - 例 6号 = 🌾🌾✨ ｜ 🍚💧🔥 ／ 9号 = 💧💧✨ ｜ 🌾🍚🔥。全キャラ同じ形で属性だけが違う
- 先攻1手目の「エネコロ2個」は**左・中**。「相手の次エネコロ-1」も**右が振れなくなる**（重なっても下限1＝左のみ）
- チップ在庫は3個で共通。差し替え先は **3面×3個＝9スロット**
- **既定は空白ではなく埋まっている**。プレイヤーはそこから差し替える。チップを外すと既定の面（素の面）に戻る＝**空きスロットは存在しない**
- 素の面はチップ在庫に入らない。装着済みチップは外すと在庫に戻る。キャラ間の付け替えは自由
- **実装メモ**: `char.slots` の並びは v5 のまま `[属性,属性,他属性,他属性,🔥,✨]`。したがって固定はスロット **0・1・5**、カスタムは **2・3・4**（連番ではない）。並びを変えなかったのは、**既定構成の42通り回帰が v5 と1戦単位で一致する**ことを検算に使うため。画面と sim の表示は `SLOT_ORDER = [0,1,5,2,3,4]`（🔒3面 → カスタム3面）で並べ替える

### チップ一覧（4種・レア無し）
| チップ | 面の意味 | 出方 |
|---|---|---|
| 🌾 / 🍚 / 💧 / 🔥 | そのエネ1個 | 勝つたび1枚 ＋ 最初の手持ち12枚 |

✨は**チップではない**（全ダイスの固定面に必ず1つある）。

### 2.1 カスタム上限（v5から据え置き）
- **3面まで積めるのは自分の属性だけ**（固定2面＋カスタム1＝3面）→ 属性チップは1個につき1枚しか載らない
- **他のエネ（他属性・🔥）は1個につき2面まで**（素の1＋チップ1）
- **✨は固定の1面だけ**（チップが無いので上限判定は不要）
- **素の面と同じ種類のチップは、そのスロットに置けない**（面が変わらないのに在庫だけ減るため）。理由は「同じ面です」
- **固定3面にはチップを置けない**。準備画面では🔒＋点線枠で押せなくしてある。理由は「固定の面」
- 上限に達する置き換えはチップをグレーにして選ばせず、理由を短く出す（6号なら「🌾は3面まで」「💧は2面まで」）
- 旧セーブ・壊れたセーブは読み込み時に外して素の面へ戻す（上限違反・廃止された✨チップは在庫に返す）
- 実装: `validateDie` / `validateSlots` / `canPlaceChip(char, chips, die, slot, chip)` / `repairDie` / `repairSlots`
  （`limitFor(char, kind)` = 属性なら `LIMIT_ATTR=3` / それ以外は `LIMIT_OTHER=2`。`FIXED_SLOTS=[0,1,5]` ・`CUSTOM_SLOTS=[2,3,4]`）

### 2.2 手持ちチップ（12枚・選ばせない）
- **属性3枚 ＋ 他3種で9枚（4・3・2）＝合計12枚**。他3種の配り方は**技プール7つでの需要が多い順**（内訳表は `docs/characters.md`）
- 属性3枚は「3個のダイスに1枚ずつ」でちょうど使い切れる枚数（上限が属性3面＝固定2＋カスタム1のため）
- **9枠に対して12枚あるので必ず余る**。全部は載らない＝**何を諦めるか**が準備画面の判断
- **最初にキャラを選んだ瞬間に自動で在庫に入る**（初回のみ）。ピッカーは作らない
- 2周目以降・再開時・負けて周をやり直すときには増えない（集めたチップで戦う報酬ループを残す）
- 実装: `engine.js` の `START_CHIPS`（キャラid → 種類ごとの枚数）と `startChips(charOrId)`。セーブの `granted` フラグで初回判定

## 3. 技（プール7つ→4つ・属性中心）※v5から変更なし

- プールの内訳はキャラ共通: **安定（コスト1）×2 ／ 中（2）×2 ／ ロマン（3）×2 ／ 支え（回復か半減）×1**
- **7技のうち5技は「属性技」**＝自分の属性を1個以上コストに含む。**残り2技は「サブ技」**
- **★（既定4技）は 属性技3＋サブ技1**。選ぶのは4つ。区分の縛りは無い。**バトル中は変えられない**
- CPUは**常に★の4技・素の面**を使う

## 4. 蔵めぐり（唯一のモード）
CPU6体をランダム順に倒す／**勝つとチップ1枚**／負けたらその周は終了／6体倒したら1周クリア。
ドロップ表は倒した相手の**タイプ**（🫧泡→🍚寄り／🌸香→💧寄り）に依存する（属性ではない）。**レア枠は v6 で廃止**。

## 5. 画面（4枚）

### ① キャラ選択
6枚のカード（絵文字・名前・タイプ・属性バッジ・HP・エネコロ6面・キャラコロ6面）。エネコロ6面は🔒3面→カスタム3面の順で出す。上に「蔵めぐり ●●●○○○」の1行。

### ② 準備（375×812に収める）
1. **キャラ**（絵文字・名前・属性バッジ・HP）1行
2. **技プール7行**（区分・技名・コスト絵文字・威力・当たり目→効果）。タップで選択トグル。4つ選ぶと「たたかう」が押せる
3. **エネコロ3個**（左・中・右の3行。1行＝**🔒固定3面＋カスタム3面**。あいだに切れ目を入れる）。カスタム面はタップで**チップ選択シート**が下から出る（0枚・上限・同じ面はグレーで理由つき）／「はずす」で既定の面へ
4. **チップ**（`n/9枠　のこり/ぜんぶ` の1行 ＋ 4種を `🌾2/3` の形で）。置いた分と残りが同時に見える
5. **たたかう**ボタン（技が4つ揃っていれば押せる。9枠は常に埋まっているので条件にしない）

### ③ バトル
上＝相手（絵文字・属性・HPバー）→相手のダイス置き場→自分のダイス置き場→下＝自分→技ボタン4つ。
各ダイスの真下の6面は**上段＝🔒固定3面／下段＝カスタム3面**の2段。
属性の有利が出た手番は結果行に「有利+2」とだけ足す（1語。専門数値は出さない）。

### ④ 結果
勝ち/負け・「🍚をもらった！」（1枚だけ）・「蔵めぐり ●●●○○○」・つぎへ／やめる。

### ① 42通りの回帰（`node sim/sim.js 2000` / `--noadv`）

| 勝率レンジ | **42.1〜58.9%** | **35.8〜69.9%** | OFF 35〜65% / ON 30〜70% |

### ② 構成の探索（`node sim/sim.js 2000 --v3`・3すくみON・`sim/out/v6_v3_2000.md`）
| キャラ | 属性 | 既定の6体まわし | 上限内最強 | 手持ち12枚＋技自由 | 手持ち12枚（★4技） |
|---|---|---|---|---|---|
| 🏺協会6号 | 🌾米 | 51.1% | 89.3% | 88.9% | **88.3%** |
| 🍶協会7号 | 🍚麹 | 52.3% | 84.6% | 84.3% | 76.9% |
| 🍈協会9号 | 💧水 | 48.1% | 84.8% | 84.9% | 84.7% |
| ❄️協会10号 | 🌾米 | 49.9% | **89.6%** | **89.8%** | 80.8% |
| 🍏協会14号 | 💧水 | 47.1% | 76.8% | 76.2% | 69.7% |
| 🧬協会1801号 | 🍚麹 | 50.6% | 82.8% | 82.3% | 82.2% |

- **上限内最強 vs 既定 = 89.6%（10号）／目標90%以下 → OK**。v5の89.8%からほぼ動かなかった。スロットを12→9に削っても天井が下がらないのは、**最強型が「同じ構成の3個」で、1個あたり2枚しか使わない**ため（例 10号 = 🔥🌾＋素の🔥）。削ったのは4枚目の枠＝もともと最強型が使っていなかった枠だった
- ダイス1個の候補は 26通り → **13通り**（枠が1つ減ったぶん半減）
- 技セット総当たり（C(7,4)=35・素の面）で70%超はゼロ。強さの源はダイスの積み方（v5と同じ）
- ドロップ期待値（1周6勝）: 🌾1.00 / 🍚2.00 / 💧2.00 / 🔥1.00

### ③ 残った懸念（数値では直していない・裁定待ち）
- **手持ち12枚だけで天井（89.8%）に届く**。v5は「初期6枚の最良77.4%」と「上限内最強89.8%」に12ptの差があり、そこが周回の報酬だった。v6は12枚あれば最強型（1個2枚×3個＝6枚）を最初から組めるので、**チップを集める意味が「★4技のままでも88.3%」という形でほぼ最初から手に入る**。減らすなら手持ちを12→9枚未満にするか、属性チップを3枚→2枚にするのが最小の一手（どちらもルール変更なので裁定が要る）
- 1801号の平均手番4.8〜5.9は v4 から既知（自傷10が支配）。持ち味を優先して据え置き
