# 醸しコロ 仕様 v5（属性制・固定2面の復活・属性3すくみ／2026-09-04 実装）

v3〜v4の経緯は `docs/spec_v3.md`（記録用・v5へ移行済み）に残してある。v2の基本ルールは `docs/spec.md`。
キャラ定義（HP・素の6面・技プール7つ・属性）は **`docs/characters.md` が正**。この文書はルールと数値の枠だけ持つ。

## v5で変えた6つ（2026-09-04・ユーザー裁定。この枠は動かさない）
1. **属性は3つ**: 🌾米 / 🍚麹 / 💧水。**🔥温度と✨万能は属性ではなく、全キャラ共通の脇役**
2. **6体を2体ずつ割り振る**: 🌾米＝協会6号・協会10号 ／ 🍚麹＝協会7号・協会1801号 ／ 💧水＝協会9号・協会14号
3. **固定2面が復活**: エネコロ1個＝**固定2面（属性×2）＋カスタム4面**。カスタム4面の初期値は**残り2属性＋🔥＋✨**
   → 初期ダイスは「属性2＋他属性1+1＋🔥＋✨」で**全キャラ同じ形・属性だけが違う**
4. **上限を緩めた**: 同じエネは1個につき**3面まで**（固定2面込み）／✨は1個につき1面まで／**素の面と同じチップは置けない**（据え置き）
5. **初期チップは6枚**: 自分の属性チップ×2 ＋ それ以外の4種（他属性2つ・🔥・✨）×1枚ずつ。**最初にキャラを選んだときに自動で在庫へ**（初回のみ・選ぶピッカーは作らない）
6. **属性3すくみ**: **麹→米→水→麹**（麹が米を糖化する／米が水を吸う／水が麹を溶かす）。有利な側は**攻撃技の成功時ダメージ +5**（固定。倍率にしない）

## v2から変えないもの（憲法）
- 戦略は「**どの技を狙うか**」だけ。振り直しは無い。選択肢を足さない
- 効果の語彙は5つ（`+N` / `自分にN` / `相手の次エネコロ-1` / `次に受けるダメージ半減` / `回復N`）。**足さない**（3すくみの+5は「効果」ではなくルール側の加算）
- キャラコロは画面で転がる。UIに専門数値（成功率%・日本酒度など）を出さない。二つ名も出さない
- ターンの流れ・しずく5・とくせい「ロマン」・先攻1手目エネコロ2個・前の手番の技は選べない
- 数値は全部叩き台。`sim/` で実測してから確定

## 1. 属性と3すくみ

| 属性 | キャラ | 有利を取る相手 |
|---|---|---|
| 🌾米 | 🏺協会6号 / ❄️協会10号 | 💧水（米が水を吸う） |
| 🍚麹 | 🍶協会7号 / 🧬協会1801号 | 🌾米（麹が米を糖化する） |
| 💧水 | 🍈協会9号 / 🍏協会14号 | 🍚麹（水が麹を溶かす） |

- 有利な側は **攻撃技が成功したときのダメージに +5**（固定値・倍率にしない）
- **しずく（失敗時の5ダメージ）には乗らない**。回復技・守り技にも乗らない
- 🫧泡 / 🌸香の「タイプ」は残っているが**戦闘の相性は持たない**（蔵めぐりのドロップ表だけに効く）
- 実装: `engine.js` の `TYPE_ADV`（有利表）＋ `ADV_BONUS = 5`。`resolveTurn` と `cpuChoose` が同じ判定を使う
- **切り替えフラグ**: `E.setTypeAdv(true|false)`（既定ON）。`E.typeAdvOn()` で現在値。simは `--noadv` でOFF側を測る

## 2. エネコロ（固定2面＋カスタム4面 × 3個）

- **左・中・右**の3個。表示順＝振るときの並び。**3個それぞれ別々にカスタムできる**
- 1個の6面 = **スロット0・1 = 固定面（属性×2・チップ不可・🔒表示）** ＋ **スロット2〜5 = カスタム4面**
- カスタム4面の初期値は **残り2属性 ＋ 🔥 ＋ ✨**（例 6号 = 🌾🌾｜🍚💧🔥✨ ／ 9号 = 💧💧｜🌾🍚🔥✨）
- 先攻1手目の「エネコロ2個」は**左・中**。「相手の次エネコロ-1」も**右が振れなくなる**（重なっても下限1＝左のみ）
- チップ在庫は3個で共通。差し替え先は **4面×3個＝12スロット**
- 素の面はチップ在庫に入らない。装着済みチップは外すと在庫に戻る。キャラ間の付け替えは自由

### チップ一覧（5種）
| チップ | 面の意味 | 出方 |
|---|---|---|
| 🌾 / 🍚 / 💧 / 🔥 | そのエネ1個 | 勝つたび（通常枠） |
| ✨ | 万能1個（どれか1つの代わり） | レア枠（3勝ごと）＋初期チップに1枚 |

### 2.1 カスタム上限（v5で緩めた）
- **同じ種類のエネ（🌾🍚💧🔥それぞれ）は1個につき3面まで**（固定2面を含めて数える。v4までは2面）
  → 属性チップは「固定2＋1」で3面が上限。他属性・🔥は「素の1＋2」で3面まで積める
- **✨は1個につき1面まで**（素の✨面もこの上限に含める。✨チップを置くには先に素の✨面を潰す必要がある）
- **素の面と同じ種類のチップは、そのスロットに置けない**（面が変わらないのに在庫だけ減るため）。理由は「同じ面です」
- **固定2面にはチップを置けない**。準備画面では🔒＋点線枠で押せなくしてある。理由は「固定の面」
- 上限に達する置き換えはチップをグレーにして選ばせず、理由を短く出す（「🌾は3面まで」「✨は1面まで」等）
- 旧セーブ・壊れたセーブは読み込み時に外して素の面へ戻す（上限違反は在庫に返す）
- 実装: `engine.js` の `validateDie` / `validateSlots` / `canPlaceChip(char, chips, die, slot, chip)` / `repairSlots`
  （`LIMIT = {rice:3, koji:3, water:3, heat:3, wild:1}` ・`SLOTS_N = 6` ・`FIXED_N = 2`）

### 2.2 初期チップ（6枚・選ばせない）
- **自分の属性チップ×2 ＋ それ以外の4種（他属性2つ・🔥・✨）×1枚ずつ＝合計6枚**
- **最初にキャラを選んだ瞬間に自動で在庫に入る**（初回のみ）。準備画面のピッカーは作らない
- 2周目以降・再開時・負けて周をやり直すときには増えない（集めたチップで戦う報酬ループを残す）
- 配られた6枚は普通の在庫チップ。上限ルールも「同じ面です」もそのまま効く
- 実装: `engine.js` の `START_CHIPS = { attr:2, other:1 }` と `startChips(charOrId)`。セーブの `granted` フラグで初回判定

## 3. 技（プール7つ→4つ・属性中心）

- プールの内訳はキャラ共通: **安定（コスト1）×2 ／ 中（2）×2 ／ ロマン（3）×2 ／ 支え（回復か半減）×1**
- **7技のうち5技は「属性技」**＝自分の属性を1個以上コストに含む。**残り2技は「サブ技」**＝属性を含まず、🔥や他属性を主軸にする
- **★（初期4技）は 属性技3＋サブ技1**。多くのキャラはサブ技枠が支え技（コスト🍚🔥など）で、14号だけ中技の金沢香がサブ
- 選ぶのは4つ。区分の縛りは無い。**バトル中は変えられない**（準備画面でだけ組む）
- CPUは**常に★の4技**を使う（CPU側には選ばせない）
- v5で変えたのは**コストだけ**。技名・威力・効果・当たり目・HP・キャラコロは据え置き（差分表は `docs/characters.md`）

## 4. 蔵めぐり（唯一のモード）
v3から変更なし。CPU6体をランダム順に倒す／勝つとチップ1枚／3勝ごとにレア（✨）1枚／負けたらその周は終了／6体倒したら1周クリア。
ドロップ表は倒した相手の**タイプ**（🫧泡→🍚寄り／🌸香→💧寄り）に依存する（属性ではない）。

## 5. 画面（4枚）

### ① キャラ選択
6枚のカード（絵文字・名前・タイプ・**属性バッジ**・HP・エネコロ6面・キャラコロ6面）。上に「蔵めぐり ●●●○○○」の1行。

### ② 準備（375×812に収める）
1. **キャラ**（絵文字・名前・**属性バッジ**・HP）1行
2. **技プール7行**（区分・技名・コスト絵文字・威力・当たり目→効果）。タップで選択トグル。4つ選ぶと「たたかう」が押せる
3. **エネコロ3個**（左・中・右の3行。1行＝🔒固定2面＋カスタム4面）。カスタム面はタップで**チップ選択シート**が下から出る（0枚・上限・同じ面はグレーで理由つき）／「はずす」で素の面へ
4. **在庫**（1行。3個で共通）
5. **たたかう**ボタン

### ③ バトル
上＝相手（絵文字・**属性**・HPバー）→相手のダイス置き場→自分のダイス置き場→下＝自分（絵文字・**属性**・HPバー）→技ボタン4つ。
**属性の有利が出た手番は結果行に「有利+5」**とだけ足す（1語。専門数値は出さない）。

### ④ 結果
勝ち/負け・「🍚をもらった！」・「蔵めぐり ●●●○○○」・つぎへ／やめる。

## 7. simで測る項目（`node sim/sim.js`）

1. **回帰**: `node sim/sim.js 2000`（42通り＝21組×先攻後攻）。**3すくみ ON / OFF（`--noadv`）の両方**を測る。勝率・平均手番・成功率・6体の総合勝率
2. **技セット総当たり**: C(7,4)=35 × 相手6体
3. **ダイス総当たり**: 1個ぶんの候補を上限内で全列挙（**1キャラ38通り**）→ 上位10で順序つき直積（1000通り）
4. **上限内最強 vs 初期構成**: 上位10ダイス × 上位10技セットで詰める。**目標は85%以下**
5. **ドロップ期待値**
6. **初期チップ6枚の最良 vs 初期構成**: 面の集合に畳んで在庫で組める並びを全列挙（1個の面の集合26通り・**在庫内の並び5,470通り**）

> §3・§6の全列挙が数万通りに膨らむため、v5では**面の集合で畳んでから上位を詰める2段階**にした（v4の「1個の候補26通り→26³」を踏襲した形）。

### ① 42通りの回帰（3すくみ ON / OFF）

| 目標未達 | 35件 | 12件 | — |

**6体の総合勝率**

| キャラ | 属性 | ON | OFF |
|---|---|---|---|
| 🏺協会6号 | 🌾米 | 55.6% | 56.1% |
| 🍶協会7号 | 🍚麹 | 53.3% | 52.1% |
| 🍈協会9号 | 💧水 | 48.3% | 49.8% |
| ❄️協会10号 | 🌾米 | 51.2% | 51.3% |

- **3すくみONは狙いどおり組ごとの勝率を広げた**（OFF 39.8〜74.2% → ON 21.7〜90.4%）。有利側の+5が効くのは「6号 vs 14号 90.4%」「10号 vs 14号 89.8%」「9号 vs 10号 21.7%」など、属性の相性が噛み合った組
- **総合勝率は ON/OFF でほとんど動かない**（差は最大1.5pt）。3すくみは有利と不利が打ち消し合うので、キャラの強さの序列は変わらず**組ごとの起伏だけが増える**
- 目標帯（勝率35〜65%）を外れる件数は ON 35件 / OFF 12件。**目標外だが指示どおり数値では直していない**
- 平均手番が6未満なのは 1801号が絡む組（4.8〜5.9）＝既知の例外。ミラー戦の先攻勝率は60%未満・打ち切りゼロ
- 14号（総合41%）が一段低いのは v4 から続く傾向（★のロマン技が威力30で最弱）。属性化でも埋まっていない
