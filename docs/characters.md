# 醸しコロ キャラ図鑑 v0（2026-09-03・叩き台）

「まずキャラを確立する」ための設計書。数値は全部叩き台。ここが固まってから spec.md を v2 に書き換える。

## 本物のプラコロから借りる骨格（調査係 2026-09-03）
- **技は先に宣言する**（狙う）→ キャラコロ＋エネコロ3個を**同時に振る**
- エネコロがコスト通り揃えば成功。**キャラコロの「向き」**が技の指定と一致すれば**キャラコロ効果**が乗る
- キャラコロはフィギュアそのもの。造形で出やすい向きが違う＝キャラの個性
- 使った技は成否を問わず**次の手番に使えない**（毎ターン違う技を狙う）
- 先攻1ターン目だけエネコロ2個（先攻有利の是正。v1で悩んだ先攻問題はこれで解ける）

## キャラを「ポケモンっぽく」立たせる5点
1. **タイプ**（＝主なエネルギー）: 🍄菌 / 🌾米 / 💧水。🔥熱は全員が少し使う副エネルギー
2. **自分のエネコロ構成**（6面）: タイプ一致の面が多い。造形＝ダイス構成がキャラの個性
3. **キャラコロの癖**（6面の向き分布）: 立ち🧍 / あおむけ😴 / うつぶせ🙃 / 横向き↔️ / 逆立ち🤸。得意な向きがキャラごとに違う
4. **技4つ**: 安定技（コスト1）／中技（2）／ロマン技（3）／支え技（回復か守り）。各技に「指定の向き→キャラコロ効果」
5. **図鑑の一言**（性格）と **HP**

効果の語彙は5つだけ（足さない）: `+ダメージ` / `自分にダメージ` / `相手の次エネコロ-1` / `次に受けるダメージ半減` / `回復`

## ターンの流れ（v2案）
1. 技を1つ選ぶ（前の手番に使った技は選べない）← **狙う**
2. 「振る」でキャラコロとエネコロ3個が**画面で同時に転がる**
3. エネが揃えば成功。向きが指定と合えばキャラコロ効果。失敗は「しずく」5ダメージ
4. 交代。先攻の1ターン目だけエネコロ2個

## v1から捨てるもの（併記）
- **振り直し**: 宣言があるので戦略の芯が「どの技を狙うか」に移る。振り直しは削る（残すなら「エネコロだけ1回」に限定して、宣言との二重判断が重くないか実機で見る）
- 「出た技が払えなければ下位の技」の自動フォールバック: 宣言制と両立しないので削る
