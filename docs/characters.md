# 醸しコロ キャラ図鑑 v3（2026-09-03・酵母縛り・技プール7つ／エネコロ固定2面＋カスタム4面）

キャラは**きょうかい酵母だけ**。協会番号＝図鑑番号。麹・米・水・温度は酵母が使う**エネコロ**側に回す（2026-09-03判断）。数値は全部叩き台。

v3で変わったところは2つだけ。ルールの正は `docs/spec_v3.md`。
- 技は**7つのプールから4つ選んで**戦う（★＝v2の既定4技。選ばなくてもよい）
- エネコロ6面は**固定2面＋カスタム4面**。カスタム4面の初期値は v2 と同じ面なので、**初期状態のダイスは v2 と1面も変わらない**

## 本物のプラコロから借りる骨格（調査係 2026-09-03）
- **技は先に宣言する**（狙う）→ キャラコロ＋エネコロ3個を**同時に振る**
- エネコロがコスト通り揃えば成功。**出た目**が技の指定と一致すれば**当たり目効果**が乗る
- 造形で出やすい目が違う＝キャラの個性。使った技は**次の手番に使えない**。先攻1ターン目だけエネコロ2個
- 手持ちの技は**7枚から4枚を選ぶ**（本家と同じ枚数）

## 酵母を「ポケモンっぽく」立たせる5点
1. **タイプ**: 🫧泡（発酵力）/ 🌸香（吟醸香）の2つ。相性は付けない（足さない）
2. **エネコロ構成**（6面）: 🌾米 🍚麹 💧水 🔥温度 ✨万能。**固定2面**（そのキャラの土台＝コスト1技のエネ×2。外せない）＋**カスタム4面**（チップで差し替えられる）
3. **キャラコロの癖**（造形＝絵文字で決まる目の分布）: 1立ち / 2あおむけ / 3うつぶせ / 4横向き / 6逆立ち（5は無い目）
4. **技プール7つ**: 安定技（コスト1）×2 ／ 中技（2）×2 ／ ロマン技（3）×2 ／ 支え技（回復か半減）×1。ここから4つ選ぶ
5. **図鑑の一言**は sake-kb で裏が取れた事実だけ（ADR-018）。出典をカードに小さく付ける
6. **血縁**: 変異株・交雑株の関係を図鑑に書く（1601×1701→1801。控えの11号は7号の変異株）。ポケモンの進化に当たる

効果の語彙は5つだけ: `+ダメージ` / `自分にダメージ` / `相手の次エネコロ-1` / `次に受けるダメージ半減` / `回復`（v3でも足さない）

## 固定2面の決め方（2026-09-03確定）
- 固定2面＝**そのキャラのコスト1技が使うエネ×2**。6キャラすべて、v2の面構成にそのエネがちょうど2面ある
- 残り4面（✨を含む）がカスタム枠。**✨は外せる**＝「万能を捨てて2エネチップを積む」が成立する
- タイプで一律に決める案（泡=🍚🍚 / 香=💧💧）は、6号・10号・1801号のv2構成と噛み合わないので採らなかった

## 新技18個の狙い（2026-09-03）
- **目の選択肢を増やすためだけに足した**。効果の語彙は5つのまま増やしていない
- v2は9号が全技4、10号が全技2で「目を狙う」判断が無かった。新技は**そのキャラがまだ使っていない目**に割り当てた（9号・10号・14号・6号は新技3つとも新しい目）
- コストのエネも既存技とずらしてある。「どのチップを積むか」で使える技が変わる＝準備画面の判断になる
- 「次に受けるダメージ半減」を当たり目効果に使ったのは2つだけ（9号ねかせる／1801ふんばる）。engineに1キー足りないなら+10に置き換えてよい（`spec_v3.md` の減らす案）

## 控え（次の拡張候補・KBで裏取り済み）
- **No.701 🫧 泡なし7号**: 7号の泡なし変異株（昭和43〜44年）。逸話：ホノルル酒造の泡なし酵母（協会6号の変異）が着想源で、顕微鏡の気泡付着性で見分ける方法を熊谷知栄子が発見、約1,500株を検索（醸協 101(9) 2006 p.662）。「泡を立てない」＝泡タイプの技が使えない代わりに何かを持つ隠しキャラ向き
- **花酵母 AK-1**: 秋田県醸造試験場（醸協 89(11) 1994 p.906）。由来の花はKBに記載なし
- **協会11号**: 協会7号のアルコール耐性変異株（昭和50年、清酒製造技術 p.198）。ユーザー判断で10号と入れ替え、控えへ（2026-09-03）

## 落としたもの
- 10号の「異数体（2n+1）」ネタ: 一般性が無いのでやめた（ユーザー判断 2026-09-03）。とくせい「エネコロ常時4個」も一緒に撤回
- 黄麹・乳酸菌・山田錦・雄町（v0）: 種族が混ざるので酵母縛りに伴い削除。麹・米はエネコロへ

- タイプ一律の固定2面（泡=🍚🍚 / 香=💧💧）: v2構成と噛み合わず、初期ダイスを変えてしまうので却下（2026-09-03）
