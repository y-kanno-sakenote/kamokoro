# 醸しコロ キャラ図鑑 v5（2026-09-04・酵母縛り・属性制／技プール7つ／固定2面＋カスタム4面）

キャラは**きょうかい酵母だけ**。協会番号＝図鑑番号。麹・米・水・温度は酵母が使う**エネコロ**側に回す（2026-09-03判断）。数値は全部叩き台。
ルールの正は `docs/spec_v5.md`。

## v5で変わったこと（2026-09-04・ユーザー裁定）
- **属性は3つ**: 🌾米 / 🍚麹 / 💧水。**🔥温度と✨万能は属性ではなく、全キャラ共通の脇役**
- **6体を2体ずつ割り振る**: 🌾米＝6号・10号 ／ 🍚麹＝7号・1801号 ／ 💧水＝9号・14号
- **固定2面が復活**。エネコロ1個は **固定2面（属性×2）＋カスタム4面**。カスタム4面の初期値は**残り2属性＋🔥＋✨**
  → 初期の6面はどのキャラも同じ形で、**属性だけが違う**（例 6号 🌾🌾｜🍚💧🔥✨ ／ 9号 💧💧｜🌾🍚🔥✨）
- **上限**: 同じエネを**3面まで積めるのは自分の属性だけ**（固定2＋チップ1）／他のエネ（他属性・🔥）は**2面まで**／✨は1面まで／素の面と同じチップは置けない（2026-09-05に締めた）
- **初期チップは6枚**: 自分の属性チップ×2 ＋ それ以外の4種（他属性2つ・🔥・✨）×1枚ずつ。最初にキャラを選んだときに自動で在庫へ（初回のみ・ピッカーは作らない）
- **技は属性中心**: 7技のうち**5技は自分の属性を1個以上含む（属性技）／2技は属性を含まない「サブ技」**。★4技は**属性技3＋サブ技1**。技名・威力・効果・当たり目は据え置きで、**コストだけ組み替えた**
- **属性3すくみ**: **麹→米→水→麹**（麹が米を糖化する／米が水を吸う／水が麹を溶かす）。有利な側は**攻撃技の成功時ダメージ +2**（固定・倍率にしない・しずくには乗らない。+5→+3→+2 と実測で下げて確定＝2026-09-05）

## 本物のプラコロから借りる骨格（調査係 2026-09-03）
- **技は先に宣言する**（狙う）→ キャラコロ＋エネコロ3個を**同時に振る**
- エネコロがコスト通り揃えば成功。**出た目**が技の指定と一致すれば**当たり目効果**が乗る
- 造形で出やすい目が違う＝キャラの個性。使った技は**次の手番に使えない**。先攻1ターン目だけエネコロ2個
- 手持ちの技は**7枚から4枚を選ぶ**（本家と同じ枚数）

## 酵母を「ポケモンっぽく」立たせる5点
1. **タイプ**: 🫧泡（発酵力）/ 🌸香（吟醸香）の2つ。**戦闘の相性は持たない**（蔵めぐりのドロップ表だけに効く）。相性を持つのは**属性**（🌾🍚💧）のほう
2. **エネコロ構成**（6面 × 3個）: 固定2面＝属性×2、カスタム4面＝残り2属性＋🔥＋✨。3個（左・中・右）が**それぞれ**この構成を持ち、**個ごとに別々のチップを付け替えられる**。初期は3個とも同じ
3. **キャラコロの癖**（造形＝絵文字で決まる面の分布）: 面は漢字1文字 **静 → 湧 → 沸 → 躍 → 極**（発酵の勢いが上がっていく順）。技の当たり目はこの順に沿った**範囲**（安定技3面 / 中技2面 / ロマン技1面 / 支え技2面）
4. **技プール7つ**: 安定技（コスト1）×2 ／ 中技（2）×2 ／ ロマン技（3）×2 ／ 支え技（回復か半減）×1。ここから4つ選ぶ
5. **図鑑の一言**は sake-kb で裏が取れた事実だけ（ADR-018）。出典をカードに小さく付ける
6. **血縁**: 変異株・交雑株の関係を図鑑に書く（1601×1701→1801。控えの11号は7号の変異株）

効果の語彙は5つだけ: `+ダメージ` / `自分にダメージ` / `相手の次エネコロ-1` / `次に受けるダメージ半減` / `回復`（v5でも足さない。3すくみの+5は効果ではなくルール側）

## 控え（次の拡張候補・KBで裏取り済み）
