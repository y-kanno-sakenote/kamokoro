# 醸しコロ キャラ図鑑 v4（2026-09-04・酵母縛り・技プール7つ／エネコロは6面すべてカスタム可）

キャラは**きょうかい酵母だけ**。協会番号＝図鑑番号。麹・米・水・温度は酵母が使う**エネコロ**側に回す（2026-09-03判断）。数値は全部叩き台。

v3で変わったところは2つだけ。ルールの正は `docs/spec_v3.md`。
2026-09-04: キャラコロの面を**漢字（静・湧・沸・躍・極）**にし、技の当たり目を**面の範囲**（例「沸躍極」）で持つようにした。内部キー・面の分布・威力・コストは不変。
- 技は**7つのプールから4つ選んで**戦う（★＝v2の既定4技。選ばなくてもよい）
- （v4 / 2026-09-04）エネコロの**初期6面は全キャラ統一**＝ **🌾🍚💧🔥✨ ＋ そのキャラの得意エネ1枚**（得意エネ＝そのキャラのコスト1技のエネ。6号🌾／7号🍚／9号💧／10号💧／14号💧／1801号🍚）。**固定面は無く、6面すべてチップで差し替えられる**
- （v3.1 / 2026-09-04）エネコロは **左・中・右の3個**で、**3個それぞれ別々にカスタムできる**。初期6面は**3個とも同じ**

## 本物のプラコロから借りる骨格（調査係 2026-09-03）
- **技は先に宣言する**（狙う）→ キャラコロ＋エネコロ3個を**同時に振る**
- エネコロがコスト通り揃えば成功。**出た目**が技の指定と一致すれば**当たり目効果**が乗る
- 造形で出やすい目が違う＝キャラの個性。使った技は**次の手番に使えない**。先攻1ターン目だけエネコロ2個
- 手持ちの技は**7枚から4枚を選ぶ**（本家と同じ枚数）

## 酵母を「ポケモンっぽく」立たせる5点
1. **タイプ**: 🫧泡（発酵力）/ 🌸香（吟醸香）の2つ。相性は付けない（足さない）
2. **エネコロ構成**（6面 × 3個）: 🌾米 🍚麹 💧水 🔥温度 ✨万能。初期は**全キャラ共通で 🌾🍚💧🔥✨＋得意エネ1枚**。**6面すべてチップで差し替えられる**（v4で固定面を廃止）。3個（左・中・右）が**それぞれ**この構成を持ち、**個ごとに別々のチップを付け替えられる**（v3.1）。初期は3個とも同じ
3. **キャラコロの癖**（造形＝絵文字で決まる面の分布）: 面は漢字1文字 **静 → 湧 → 沸 → 躍 → 極**（発酵の勢いが上がっていく順）。技の当たり目はこの順に沿った**範囲**で決まる（安定技3面 / 中技2面 / ロマン技1面 / 支え技2面。面の少ないキャラは1面前後する）
4. **技プール7つ**: 安定技（コスト1）×2 ／ 中技（2）×2 ／ ロマン技（3）×2 ／ 支え技（回復か半減）×1。ここから4つ選ぶ
5. **図鑑の一言**は sake-kb で裏が取れた事実だけ（ADR-018）。出典をカードに小さく付ける
6. **血縁**: 変異株・交雑株の関係を図鑑に書く（1601×1701→1801。控えの11号は7号の変異株）。ポケモンの進化に当たる

効果の語彙は5つだけ: `+ダメージ` / `自分にダメージ` / `相手の次エネコロ-1` / `次に受けるダメージ半減` / `回復`（v3でも足さない）

## 初期6面の決め方（v4・2026-09-04 ユーザー裁定）
- **全キャラ統一**。1個あたり **🌾🍚💧🔥✨ ＋ そのキャラの得意エネ1枚 = 6面**。左・中・右の3個とも同じ
- 得意エネ＝**そのキャラのコスト1技が使うエネ**（6号🌾／7号🍚／9号💧／10号💧／14号💧／1801号🍚）
- **固定面は廃止**。6面すべてチップで差し替えられる（上限は据え置き＝✨は1個に1面まで／同じエネは1個に2面まで／素の面と同じチップは置けない）
- 旧v3の「固定2面＋カスタム4面」からの差分は **9号と1801号だけ**（9号 🍚💧💧🔥🔥✨→🌾🍚💧💧🔥✨ ／ 1801号 🍚🍚💧🔥🔥✨→🌾🍚🍚💧🔥✨）。他4キャラは面が1つも変わらない

## 新技18個の狙い（2026-09-03）
- **目の選択肢を増やすためだけに足した**。効果の語彙は5つのまま増やしていない
- v2は9号が全技「躍」、10号が全技「湧」で「面を狙う」判断が無かった。新技は**そのキャラがまだ使っていない面**に割り当てた（9号・10号・14号・6号は新技3つとも新しい面）
- コストのエネも既存技とずらしてある。「どのチップを積むか」で使える技が変わる＝準備画面の判断になる

## 当たり目を範囲にした（2026-09-04・ユーザー裁定）
- 面は数字ではなく漢字 **静・湧・沸・躍・極**（発酵の勢いが上がる順）。数字は「ロマンが無い」ので廃止
- 当たり目は1面ではなく**面の集合**。区分ごとに幅を決めた: **安定3面 / 中2面 / ロマン1面 / 支え2面**（いずれも連続範囲。従来の1面を必ず含み、そのキャラの得意な面に寄せた）
- ロマン技だけ1面のまま＝一点狙いの見返り。「自分にN」の不利な効果（真澄の一撃・ぜんぶだす）は当たりやすくしない
- 威力・コスト・HP・エネコロ面構成・ルールは1つも変えていない。当たり目効果が乗りやすくなるぶん決着が少し早い（sim 2000: 平均手番 7.4 → 7.1）

## 同一キャラ内で当たり目を散らした（2026-09-04・2回目）
- 「そのキャラの die に無い面」を除いた結果、1キャラの中で当たり目が丸かぶりの技が増えていた（7号は ぷくぷく＝高泡＝きじゅん が全部「静湧」など）。**同じ面数の技どうしが同じ範囲を持たない**ように振り直した
- 使えるのは**そのキャラの die にある面だけ**。連続範囲を優先し、足りないときだけ飛び飛び（7号きじゅん「静極」など。die に沸が無いキャラでは飛び飛び表記でも実質は隣どうし）
- 変えたのは `moves[].hit` だけ。**ルール・威力・コスト・HP・エネコロ・die は不変**。「自分にN」の真澄の一撃・ぜんぶだすも1面のまま
- 重複ゼロ（全6キャラ×7技）。10号は元から重複が無く**無変更**
- 一度は9号の安定2技と7号の中・支え技を型どおり広げたが、成功率78%・勝率29%まで振れたので**当たる確率を元のまま**にして範囲だけずらす形に戻した
- 実測（`node sim/sim.js 2000`）: 勝率 40.3〜63.6%（目標35〜65%内）・平均手番 7.0・成功率 66.3%。目標外は1801号絡みの手番（4.6〜5.9）と10号系の成功率（70.2〜70.6%）だけで、いずれも既知の例外
- `--v3` 最強構成 vs 初期構成: 6号81.4／7号77.7／9号57.5／10号77.7／14号70.9／1801号45.6%（最大81.4%・目標85%以下）

## エネコロを左・中・右の3個に分けた（2026-09-04・v3.1・ユーザー裁定）
- 「ゲーム開始時に手持ちチップを付け替えるイメージ」。**1種類の面構成を3個振る**のをやめ、**3個それぞれ別々にカスタム**できるようにした
- 各キャラの「固定2面／カスタム4面の初期値」は**3個ともこの表のとおり**。初期状態は v3 と1面も変わらないので、**42通り（21組×先攻後攻）の回帰は完全一致**（勝率40.3〜63.6%・平均手番7.0・成功率66.3%）
- 上限（✨は1面まで／同じエネは固定込み2面まで）は**1個ごと**に効く。3個合計の比率は v3 と同じ
- 振る並びは左→中→右。**先攻1手目の2個は左・中**、「相手の次エネコロ-1」も**右が振れなくなる**（下限1＝左のみ）
- チップ在庫は3個で共通。差し替え先が4→12スロットに増えたぶん周回は長くなる（ドロップ率・レア率は据え置き＝意図どおり）
