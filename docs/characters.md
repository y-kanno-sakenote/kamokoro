# 醸しコロ キャラ図鑑 v1.2（2026-09-03・酵母縛り・叩き台）

キャラは**きょうかい酵母だけ**。協会番号＝図鑑番号。麹・米・水・温度は酵母が使う**エネコロ**側に回す（2026-09-03判断）。数値は全部叩き台。

## 本物のプラコロから借りる骨格（調査係 2026-09-03）
- **技は先に宣言する**（狙う）→ キャラコロ＋エネコロ3個を**同時に振る**
- エネコロがコスト通り揃えば成功。**キャラコロの「向き」**が技の指定と一致すれば**向き効果**が乗る
- 造形で出やすい向きが違う＝キャラの個性。使った技は**次の手番に使えない**。先攻1ターン目だけエネコロ2個

## 酵母を「ポケモンっぽく」立たせる5点
1. **タイプ**: 🫧泡（発酵力）/ 🌸香（吟醸香）の2つ。相性は付けない（足さない）
2. **エネコロ構成**（6面）: 🌾米 🍚麹 💧水 🔥温度 ✨万能。技のコストに合わせてキャラごとに違う
3. **キャラコロの癖**（造形＝絵文字で決まる向き分布）: 立ち🧍 / あおむけ😴 / うつぶせ🙃 / 横向き↔️ / 逆立ち🤸
4. **技4つ**: 安定技（コスト1）／中技（2）／ロマン技（3）／支え技（回復か守り）。各技に「指定の向き→効果」
5. **図鑑の一言**は sake-kb で裏が取れた事実だけ（ADR-018）。出典をカードに小さく付ける
6. **血縁**: 変異株・交雑株の関係を図鑑に書く（1601×1701→1801。控えの11号は7号の変異株）。ポケモンの進化に当たる

効果の語彙は5つだけ: `+ダメージ` / `自分にダメージ` / `相手の次エネコロ-1` / `次に受けるダメージ半減` / `回復`

## 控え（次の拡張候補・KBで裏取り済み）
- **No.701 🫧 泡なし7号**: 7号の泡なし変異株（昭和43〜44年）。逸話：ホノルル酒造の泡なし酵母（協会6号の変異）が着想源で、顕微鏡の気泡付着性で見分ける方法を熊谷知栄子が発見、約1,500株を検索（醸協 101(9) 2006 p.662）。「泡を立てない」＝泡タイプの技が使えない代わりに何かを持つ隠しキャラ向き
- **花酵母 AK-1**: 秋田県醸造試験場（醸協 89(11) 1994 p.906）。由来の花はKBに記載なし
- **協会11号**: 協会7号のアルコール耐性変異株（昭和50年、清酒製造技術 p.198）。ユーザー判断で10号と入れ替え、控えへ（2026-09-03）

## 落としたもの
- 10号の「異数体（2n+1）」ネタ: 一般性が無いのでやめた（ユーザー判断 2026-09-03）。とくせい「エネコロ常時4個」も一緒に撤回
- 黄麹・乳酸菌・山田錦・雄町（v0）: 種族が混ざるので酵母縛りに伴い削除。麹・米はエネコロへ
- 協会11号: 10号と入れ替え（ユーザー判断）。7号の変異株という血縁は控えでも活きる
