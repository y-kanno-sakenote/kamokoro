# 醸しコロ 仕様 v2（宣言制・2026-09-03。数値は叩き台、simで確定する）

プラコロ本家の骨格（技を宣言→キャラコロ＋エネコロを同時に振る→出目一致で追加効果）を、きょうかい酵母6株で組んだ1対1バトル。単一HTML・オフライン・CPU戦・10分で終わる。
キャラの定義（HP・エネコロ構成・キャラコロの目の分布・技4つ・当たり目効果・とくせい）は **`docs/characters.md` が正**。この文書はルールと数値の枠だけ持つ。

（2026-09-04: キャラコロの面を**漢字（静・湧・沸・躍・極）**にし、当たり目を**面の範囲**にした。威力・コスト・面の分布は不変）

## 憲法（変えない）
- 戦略は「**どの技を狙うか**」だけ。振り直しは無い（2026-09-03確定）。選択肢を足さない
- キャラコロは**画面で転がる**。裏で振って結果だけ出さない
- UIに専門数値（日本酒度・酸度・成功率%など）を出さない。二つ名も出さない
- 図鑑の事実は sake-kb で裏が取れたものだけ（ADR-018）
- 数値は全部叩き台。`sim/` で実測してから確定

## ダイス
- **キャラコロ**（6面）: 面は漢字1文字 **静・湧・沸・躍・極** の5種（発酵の勢いが上がっていく順）。どの面が何個あるかはキャラごと（characters.md）
- **エネコロ**（6面×3個）: 🌾米 🍚麹 💧水 🔥温度 ✨万能。面の内訳はキャラごと。✨はどれか1つの代わり

## ターンの流れ
1. 技を1つ選ぶ。**前の手番に自分が使った技は選べない**（成否を問わず）
2. 選んだ瞬間にキャラコロ1個＋エネコロ3個が同時に転がる（**先攻の1手目だけエネコロ2個**）
3. エネコロがコスト通り揃えば**成功**：威力ぶんダメージ（支え技は回復/半減）。さらに**出た面が技の当たり目に入っていれば**当たり目効果が乗る。当たり目は1面ではなく**面の範囲**（安定技3面 / 中技2面 / ロマン技1面 / 支え技2面。表記は該当する漢字を静→湧→沸→躍→極の順に並べる。例「沸躍極」）
4. 揃わなければ**しずく**（5ダメージ）。1801号はとくせい「ロマン」で失敗時に自分に10
5. 交代。HPが0以下になったら終了。先攻はランダム

## 効果の語彙（5つだけ・足さない）
| 効果 | 処理 |
|---|---|
| +N | そのダメージにN加算 |
| 自分にN | 攻撃側もNダメージ（半減の対象外） |
| 相手の次エネコロ-1 | 相手の次の手番のエネコロが1個減る（下限1・重複しない） |
| 次に受けるダメージ半減 | 次に相手から受ける1回のダメージを半分（切り上げ）にして消費。しずくでも消費 |
| 回復N | HPをN回復（上限は最大HP） |

## CPUの技選び（単純に）
- 各技の成功確率をエネコロ構成から厳密計算（6^3通り、先攻1手目は6^2）
- 期待ダメージ＝成功率×威力（当たり目効果の+Nは**当たり目の面が出る確率の合計**を掛けて加算）で最大の技を選ぶ。前の手番の技は除外
- 自分のHPが最大の30%以下で、回復技が使えて、相手を今回倒せる技が無いときは回復技を選ぶ

## バランス目標（`node sim/sim.js 2000`）
- 全36組（同キャラ含む21組×先攻後攻）で勝率35〜65%
- 1戦の平均手番 片側6〜10
- 宣言した技の成功率が全体で40〜70%（「狙って振る」緊張感の帯。しずく率30〜60%と同義）
- 先攻勝率（ミラー戦）60%未満。超えるなら先攻1手目2個のルールが効いているか確認
- **例外（2026-09-03裁定）**: 1801号（とくせい「ロマン」・HP95・バースト40）が絡む組は平均手番5〜6でよい。紙耐久のロマン枠という個性を、手番目標より優先する

### 実測（2026-09-03、`node sim/sim.js 2000`、`sim/out/sim_v2_final_2000.txt`）
- 勝率: 36組すべて35〜65%（最も偏るのは 6号先攻 vs 1801号 = 60.7%）。キャラ別総合勝率は46〜55%
- 平均手番: 1801号が絡む6組が4.9〜6.0で例外扱い、他は6〜10
- 宣言技の成功率: 全体66%。泡組どうしは68〜69%で上限すれすれ（技①がコスト1で通りやすい構造。上げるならエネコロ面の変更が要る＝v3の宿題）

## 画面（3枚だけ）
1. キャラ選択：6枚（絵文字・名前・タイプ・HP・ダイス面構成）。相手はCPUがランダム
2. バトル：上＝相手（絵文字・HPバー・残りHP）→**相手のダイス置き場**（小さめ。手番でないときは直前の出目を薄く残す）→**自分のダイス置き場**（キャラコロ大＋エネコロ3個）→**自分の面構成1行**（🎲 エネコロ6面＋キャラコロ6面の漢字。狙う材料なので常時表示。確率は出さない）→下＝自分（絵文字・HPバー・残りHP）→技ボタン4つ（前の手番の技は「さっき使った」印付きで押せない。コスト・威力は見える）。**技を押す＝宣言＋振る**（ボタンは技4つだけ）。結果は1行（「高泡！ 25ダメージ　静ぴったり！」「しずく…」「まんたん！」）。ログは直近3行。相手の手番は自動（1秒）。375×812で技ボタンまで1画面
   - 2026-09-03: ダイスを上下に分けた（同じ場所で転がすと誰の出目か分からない）／面構成を常時表示（「配分が分からないと狙えない」）
3. 結果：勝ち/負け・もう一回・キャラ選択へ

スマホ縦持ち前提。演出はCSSの転がりアニメだけ。

## 減らす案（併記）
- 当たり目効果を無くし「エネが揃うか」だけにする最小版（キャラコロが飾りになるので却下寄り）
- 技4→3（支え技を削る）はユーザー判断で却下済み

## 2026-09-04の判断
- キャラコロの面を数字（①②③④⑥）から**漢字 静・湧・沸・躍・極**へ。「数字だとロマンが無い」（ユーザー裁定）。並びは発酵の勢いが上がっていく順で、当たり目の範囲指定の土台になる
- 当たり目を1面から**面の集合（連続範囲）**へ。安定3面 / 中2面 / ロマン1面 / 支え2面。従来の1面を必ず含み、そのキャラの得意な面に寄せて広げた。「自分にN」の不利な効果は広げない
- 威力・コスト・HP・エネコロ面構成・ルールは変えていない。当たりが増えたぶん決着が早い（sim 2000: 平均手番 7.4 → 7.1、勝率レンジ 37.3〜64.6%、成功率は 66% で不変）
