# 醸しコロ 仕様 v2（宣言制・2026-09-03。数値は叩き台、simで確定する）

> **現行は v7（しずく廃止・3すくみは「有利側が先攻」）**。ルールの正は `docs/spec_v5.md`（ファイル名は据え置きで中身が v7）。この文書は v2 の基本ルール（ターンの流れ・効果の語彙・CPU・バランス目標）を持ち、v5〜v7 で変わった部分は下の追記にある。

プラコロ本家の骨格（技を宣言→キャラコロ＋エネコロを同時に振る→出目一致で追加効果）を、きょうかい酵母6株で組んだ1対1バトル。単一HTML・オフライン・CPU戦・10分で終わる。
キャラの定義（HP・エネコロ構成・キャラコロの目の分布・技4つ・当たり目効果・とくせい）は **`docs/characters.md` が正**。この文書はルールと数値の枠だけ持つ。

（2026-09-04: キャラコロの面を**漢字（静・湧・沸・躍・極）**にし、当たり目を**面の範囲**にした。威力・コスト・面の分布は不変）

## 憲法（変えない）
- 戦略は「**どの技を狙うか**」だけ。振り直しは無い（2026-09-03確定）。選択肢を足さない
- キャラコロは**画面で転がる**。裏で振って結果だけ出さない
- UIに専門数値（日本酒度・酸度・成功率%など）を出さない。二つ名も出さない
- 図鑑の事実は sake-kb で裏が取れたものだけ（ADR-018）
- 数値は全部叩き台。`sim/` で実測してから確定

## ダイス
- **キャラコロ**（6面）: 面は漢字1文字 **静・湧・沸・躍・極** の5種（発酵の勢いが上がっていく順）。どの面が何個あるかはキャラごと（characters.md）
- **エネコロ**（6面×3個）: 🌾米 🍚麹 💧水 🔥温度 ✨万能。✨はどれか1つの代わり
  - v3.1（2026-09-04）: 3個は **左・中・右**で、**個ごとに面構成を変えられる**（準備画面でチップを付け替える）。**振る並びは左→中→右**で、先攻1手目の2個は左・中（構造ルールなので固定）。「相手の次エネコロ-1」は左・中・右のうち**ランダムに1個**が振れなくなる（2026-09-06 裁定）
  - v4（2026-09-04）: 初期6面を全キャラ統一（🌾🍚💧🔥✨＋得意エネ1枚）にして固定面を廃止した。**v5で撤回**
  - v5（2026-09-04）: 固定2面が復活。1個＝固定2面（属性×2）＋カスタム4面（残り2属性＋🔥＋✨）
  - **v6（2026-09-05）: 固定3面＝属性×2＋✨×1／カスタム3面＝残り2属性＋🔥**。6面の中身はv5と同じで、**✨が固定側に移り、置ける枠が12→9に減った**

## ターンの流れ
1. 技を1つ選ぶ。**前の手番に自分が使った技は選べない**（成否を問わず）
2. 選んだ瞬間にキャラコロ1個＋エネコロ3個が同時に転がる（**先攻の1手目だけエネコロ2個**＝左・中）
3. エネコロがコスト通り揃えば**成功**：威力ぶんダメージ（支え技は回復/半減）。**出た面が技の当たり目に入っていれば**当たり目効果が乗る。当たり目は1面ではなく**面の範囲**（安定技3面 / 中技2面 / ロマン技1面 / 支え技2面。表記は該当する漢字を静→湧→沸→躍→極の順に並べる。例「沸躍極」）
4. 揃わなければ**何も起きない**（v7。相手にダメージは入らない）。失敗の代償は手順1の「前の手番の技は選べない」だけ。1801号だけはとくせい「ロマン」で失敗時に自分に10
5. 交代。HPが0以下になったら終了。**先攻は属性の3すくみで有利な側**（ミラーはランダム。v7）

## 効果の語彙（5つだけ・足さない）
| 効果 | 処理 |
|---|---|
| +N | そのダメージにN加算 |
| 自分にN | 攻撃側もNダメージ（半減の対象外） |
| 相手の次エネコロ-1 | 相手の次の手番のエネコロが1個減る（左・中・右のうちランダムに1個・下限1・重複しない） |
| 次に受けるダメージ半減 | 次に相手から受ける1回のダメージを半分（切り上げ）にして消費（v7では失敗にダメージが無いので、消費するのは成功した攻撃だけ） |
| 回復N | HPをN回復（上限は最大HP） |

## CPUの技選び（単純に）
- 各技の成功確率をエネコロ構成から厳密計算（6^3通り、先攻1手目は6^2）。v3.1では3個それぞれの面が違う前提で列挙する（左×中×右）
- 期待ダメージ＝成功率×威力（当たり目効果の+Nは**当たり目の面が出る確率の合計**を掛けて加算）で最大の技を選ぶ。前の手番の技は除外
- 自分のHPが最大の30%以下で、回復技が使えて、相手を今回倒せる技が無いときは回復技を選ぶ

- 全42通り（同キャラ含む21組×先攻後攻）で勝率35〜65%
- 1戦の平均手番 片側6〜10
- 宣言した技の成功率が全体で40〜70%（「狙って振る」緊張感の帯。失敗率30〜60%と同義）

## 画面（v2は3枚。v3で準備が1枚増えて4枚・詳しくは `docs/spec_v3.md` §4）
1. キャラ選択：6枚（絵文字・名前・タイプ・HP・ダイス面構成）。相手はCPUがランダム
2. バトル：上＝相手（絵文字・HPバー・残りHP）→**相手のダイス置き場**（小さめ。手番でないときは直前の出目を薄く残す）→**自分のダイス置き場**（キャラコロ大＋エネコロ3個）→**転がる各ダイスの真下にその個の6面**（キャラコロは漢字6面、エネコロは左・中・右それぞれの6面。狙う材料なので常時表示。確率は出さない。v3.1で1行まとめを廃止）→下＝自分（絵文字・HPバー・残りHP）→技ボタン4つ（前の手番の技は「さっき使った」印付きで押せない。コスト・威力は見える）。**技を押す＝宣言＋振る**（ボタンは技4つだけ）。結果は1行（「高泡！ 25ダメージ　静ぴったり！」「そろわず…」「まんたん！」）。ログは直近3行。相手の手番は自動（1秒）。375×812で技ボタンまで1画面
   - 2026-09-03: ダイスを上下に分けた（同じ場所で転がすと誰の出目か分からない）／面構成を常時表示（「配分が分からないと狙えない」）
3. 結果：勝ち/負け・もう一回・キャラ選択へ
- 準備画面（キャラ選択とバトルのあいだ）：技プール7つから4つ選ぶ／エネコロ3個の**カスタム3面**にチップをはめる（**9スロット**・固定3面は🔒）／**そのキャラの**チップ在庫1行（のこり/ぜんぶ）／たたかう。「持ち込み」欄はv4で廃止（v6.1はそのキャラを初めて選んだとき8枚がそのキャラの在庫に入る）

スマホ縦持ち前提。演出はCSSの転がりアニメだけ。

## 2026-09-04の判断
- キャラコロの面を数字（①②③④⑥）から**漢字 静・湧・沸・躍・極**へ。「数字だとロマンが無い」（ユーザー裁定）。並びは発酵の勢いが上がっていく順で、当たり目の範囲指定の土台になる
- 当たり目を1面から**面の集合（連続範囲）**へ。安定3面 / 中2面 / ロマン1面 / 支え2面。従来の1面を必ず含み、そのキャラの得意な面に寄せて広げた。「自分にN」の不利な効果は広げない
- 威力・コスト・HP・エネコロ面構成・ルールは変えていない。当たりが増えたぶん決着が早い（sim 2000: 平均手番 7.4 → 7.1、勝率レンジ 37.3〜64.6%、成功率は 66% で不変）

## 2026-09-04（v5: 属性制・固定2面の復活・属性3すくみ）
ユーザー裁定。詳細は `docs/spec_v5.md`、キャラ定義は `docs/characters.md`。
1. **属性は3つ**（🌾米・🍚麹・💧水）。🔥温度と✨万能は属性ではなく全キャラ共通の脇役。6体を2体ずつ割り振る（🌾=6号・10号／🍚=7号・1801号／💧=9号・14号）
2. **固定2面を復活**。エネコロ1個＝固定2面（属性×2）＋カスタム4面（初期値は残り2属性＋🔥＋✨）。差し替え先は 4×3＝12スロット
3. **上限を緩めた**: 同エネは1個につき3面まで（固定込み）／✨は1個1面まで／素の面と同じチップは置けない
4. **初期チップは6枚**（属性×2＋他4種×1）。最初にキャラを選んだときに自動で在庫へ（初回のみ・ピッカーは作らない）
5. **技は属性中心**: 7技のうち5技は属性を1個以上含み、2技は「サブ技」。★4技は属性技3＋サブ技1。**技名・威力・効果・当たり目は据え置きでコストだけ組み替えた**
6. **属性3すくみ**: 麹→米→水→麹。有利な側は攻撃技の成功時ダメージ +5（固定・倍率にしない）。`engine.js` の `setTypeAdv(bool)` で ON/OFF を切り替えられる（既定ON）。simは `--noadv` でOFF側を測る
- セーブは `v:5`。**v4以前は読まずに初期化**（例外は出さない）

## 2026-09-05（v6.1: チップ在庫をキャラごとに・ドロップ均等・初期配布を全キャラ8枚）
ユーザー裁定3点。ルールは1つも足していない（在庫の持ち方と配り方だけを変えた）。
1. **チップ在庫をキャラごとに持つ**。全キャラ共通の1プールをやめ `chips[charId]` へ。初期配布は**そのキャラを初めて選んだときにそのキャラの分だけ**（`granted[charId]`）。ドロップも**いま使っているキャラの在庫**に入り、準備画面の在庫表示もそのキャラの分だけ。→ 酵母を持ち替えると集め直しになり、天井（89.6%）に届いたあとの空白が埋まる
2. **ドロップを🌾🍚💧🔥の均等 1/4 に**。旧「倒した相手のタイプ寄り50%」を廃止。寄りの根拠だった🫧泡／🌸香は**戦闘に効かず**、相手の出る順もランダムなので**プレイヤーが寄りを活かせない**。これでタイプは図鑑の飾りだけになった
3. **初期配布を全キャラ「4種2枚ずつ＝8枚」に統一**。6号だけ🍚1枚（7枚）の例外を廃止。6号の手持ち最良が **80.3%** と目標帯（75〜80%）を **0.3pt** 超えるが誤差として受け入れる（キャラごとの例外を持つより説明が短い）
- セーブは `v:7`。**v6以前は読まずに初期化**（例外は出さない）
- 実測: 42通りの回帰は**変更前と `diff` 完全一致**（在庫の持ち方とドロップは対戦の数値に触れない）。天井も6体とも不変（最大89.6%）。手持ち最良は 6号80.3 / 7号80.0 / 9号76.8 / 10号78.4 / 14号76.3 / 1801号77.4%。ドロップ期待値は1周6勝で4種とも1.50枚（`sim/out/v7_42_2000.txt`・`sim/out/v7_v3_2000.md`）
- 実機（375×812）で確認: 6号で1戦勝つ→🌾が6号の在庫へ／キャラ選択に戻って9号を選ぶ→9号に新しく8枚が配られ、6号の分は入っていない


## 2026-09-05（v7: しずく廃止・3すくみは「有利側が先攻」）
ユーザー裁定2点。詳細は `docs/spec_v5.md`（中身はv7）。
1. **「しずく」を廃止**。技が揃わなかったら**何も起きない**（相手に5ダメージを与えない）。失敗の代償は既存の「前の手番の技は選べない」だけ。**1801号のとくせい「ロマン」（失敗すると自分に10）は据え置き**＝ゲーム唯一の失敗ペナルティ
2. **3すくみの「有利側+2ダメージ」を廃止**し、**「有利側が先攻」**に置き換えた。属性が違う組は有利側（麹→米→水→麹）が必ず先攻。**ミラー（同属性）はランダム**。「先攻1手目はエネコロ2個」は据え置き。`setTypeAdv(false)`（sim の `--noadv`）のときは従来どおり全組ランダム先攻
- ダメージ計算から属性が消えたので、**属性は先攻の決め方にだけ効く**。効果の語彙（5つ）は不変
- 技・威力・HP・コスト・キャラコロ・当たり目・チップ・在庫・ドロップ・セーブ（`v:7`）は**一切変えていない**
