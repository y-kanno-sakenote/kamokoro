# 醸しコロ 仕様 v1（2026-09-03。数値はsim 2000戦×36組で確定）

プラコロ（ポケモンのサイコロバトル。キャラコロ＋エネコロを振って技を出す「運×戦略」）の骨格を、醸造キャラで組み直した1対1バトル。単一HTML・オフライン・CPU戦。10分で終わる。

## 憲法（変えない）
- 運＝サイコロ、戦略＝「エネコロの振り直し（1回・好きな個数）」だけ。これ以外に選択肢を足さない
- UIに専門数値（日本酒度・酸度など）を出さない。技名は醸造ネタだが、知らなくても笑える言葉にする
- 数値は全部叩き台。`sim/`の大量ロールで実測してから確定する

## ダイス
- **キャラコロ**（6面）: 技①×3面 / 技②×2面 / 技③×1面。出た技がそのターンの技
- **エネコロ**（6面 × 3個）: 🌾🌾💧💧🔥✨。✨は万能（どれか1つの代わり）
  - 🌾＝米、💧＝水、🔥＝熱（温度）

## ターンの流れ
1. キャラコロを振る → 技が決まる
2. エネコロ3個を振る
3. **1回だけ**、好きなダイスを選んで振り直せる（残りは固定）← 戦略の芯
4. 決定。出た技のコストを満たしていれば発動。満たしていなければ、**下位の技でコストを満たす最強のもの**を自動で発動。どれも無理なら「しずく」（1ダメージ）
5. 相手のターンへ。HPが0になったら終了

先攻はランダム。

効果は「エネコロ+1個」「半減」の2種類だけ。これ以上足さない。

## CPUの振り直しルール
出た技のコストに当たるダイスは固定し、それ以外を振り直す。コストが既に満たされていれば振り直さない。

## バランス目標と実測（2026-09-03、`node sim/sim.js 2000`）
- 全36組（同キャラ含む21組×先攻後攻）で勝率35〜65% → **達成**（別seedで協会9号先攻の2組が65〜68%に触れる程度）
- 1戦の平均ターン数 片側5〜9 → **達成**（5.2〜8.2）
- 「しずく」率 30%未満 → 達成（1.3〜9.5%）。ただし低すぎて振り直しの緊張感が薄い。技①が1個コストなので構造的に2%前後。上げるならコスト構造の変更が要る（v2の宿題）
- 先攻有利: ミラー戦で先攻56〜66%。HP/威力では縮まらない。**v1は「先攻は少し得」と割り切って現状維持**（先攻はランダムなので期待値は公平）。縮めたければ「後攻はHP+2で開始」が実測で効く（全組48〜58%）
- 効果の重み: 乳酸菌の半減を外すと勝率50%→32%（生命線）。雄町の自傷は-8pt。黄麹の+1個は-2ptで軽い

## 画面（3枚だけ）
1. キャラ選択: 6枚のカード（絵文字・名前・持ち味の一言・HP）。タップで決定。相手はCPUがランダムに選ぶ
2. バトル: 上＝相手（絵文字・HPバー）、下＝自分。中央にダイス（大きな絵文字）。ボタンは「振る」→「振り直す/このまま」→自動進行。ログは直近3行
3. 結果: 勝ち/負け・もう一回・キャラ選択に戻る

スマホ縦持ち前提。効果音・アニメはCSSの揺れだけ（足さない）。

## 減らす案（併記）
- 効果を無くして純粋な数値勝負にする案は**却下**（乳酸菌が成立しなくなる。実測済み）
- キャラ6→4体（未検討）
- 黄麹の+1個は効きが薄いので、削って別の持ち味にする余地あり
